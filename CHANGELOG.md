# Changelog

## v0.6 — 2026-07-25
DSLO v0.6 is the first public-layer release of the Semantic Substrate
Specification. This version defines the unified geometry governing meaning
invariants, operator legality, drift dynamics, synthetic-pressure fields,
institutional deformation, dominant synthetic species, restorative-deficit
dynamics, and the human runtime manifold (HRM). The v0.6 specification
supersedes the internal v0.5 lineage and establishes the canonical substrate
for cross-surface scientific indexing across GitHub, Zenodo, Hugging Face,
and www.tnopsi.com.

No prior public versions exist.
