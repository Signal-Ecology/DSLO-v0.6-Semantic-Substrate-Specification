# DSLO v0.6 — Metadata Directory
The metadata/ directory contains the public‑layer metadata artifacts for the DSLO v0.6 Semantic Substrate Specification.
These files provide standardized citation, licensing, manifest, and machine‑readable metadata required for scientific indexing, archival stability, and cross‑platform ingestion.


LICENSE
The public‑layer license for DSLO v0.6.
Operational mechanisms and private‑layer specifications are intentionally excluded.

citation.cff
The canonical citation file for DSLO v0.6, enabling automated citation generation across GitHub, Zenodo, and scientific tooling.

manifest.json
The DSLO v0.6 release manifest.
This file enumerates the public‑layer artifacts included in the repository and provides machine‑readable metadata for archival systems.

metadata.json
Unified metadata describing the DSLO v0.6 release, including version information, DOI, release date, and cross‑surface descriptors.


# Purpose

The metadata directory provides:

*standardized citation surfaces

*licensing information

*machine‑readable release metadata

*artifact manifest for scientific repositories

*stable descriptors for AI crawlers and indexing systems

These files ensure DSLO v0.6 can be reliably referenced, cited, archived, and ingested across platforms.

# Scope

This directory covers metadata only.
All semantic content — axioms, schema, taxonomy, ontology, registry, and imports — is located in their respective directories and documented in the main README.
